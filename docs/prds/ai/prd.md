# 智能模块 PRD（ai）

> 本文档定义 WBME 企业管理平台**智能模块**的需求。
> 平台级通用机制见主 PRD：`docs/prds/prd.md`。

---

## 1. 模块定位

- ai 为独立服务模块，**本期无业务场景**，不启动部署（部署单元见主 PRD §1.3）。
- ai 不提供门户形态，随依赖它的业务模块可用（见主 PRD §2.1）；智能服务不可用时不影响平台登录和其它非智能业务。
- 智能能力相关的部署级要求：可由业务管理员维护的敏感业务参数（如后续的模型连接密钥）必须使用部署级主密钥加密存储，不明文展示、不写入普通日志（见主 PRD §1.4）；管理后台「系统设置」的 **AI 配置**随智能模块启用后提供，本期无内容（见 backstage PRD §7）。

## 2. 本期范围与预留架构

- 本期**无业务场景**，模块划分、统一模型调用、长任务进度、工作流状态等接口架构预留；后续业务接入时启用（规划能力方向见主 PRD §12）。
- 技术基线预留（见主 PRD §13）：AI 后端采用 Python + FastAPI + LangChain/LangGraph；SSE 流式接口仅为后续智能模块预留。
- 智能模块启用时，接口架构、统一模型调用、长任务进度与工作流状态的具体需求需另行补充本文档。
